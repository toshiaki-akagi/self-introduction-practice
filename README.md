# self-introduction-practice

## 概要

COACHTECH 教材 Tutorial 5-1「HTMLの基礎 ハンズオン演習」で作成した成果物です。
自己紹介として基本的なプロフィール情報、好きなものや今年の目標、問い合わせフォームなどを作成しました。タグとしては見出し用や段落、リンク遷移や画像表示、入力フォームなどを使用しました。

## 使用技術

- HTML5

## 学んだこと

- htmlの基本的な構造
- テキストやハイパーリンク、画像の表示、ユーザーからの入力を受け付ける用のタグ
- 各タグに含める属性

## 動作確認

1.VSCode上で開きたいファイルを右クリック
2.Windowsの場合は「エクスプローラーで表示する」をクリック3.開きたいファイルをダブルクリック、またはブラウザにドラッグ&ドロップ
4.hemlに修正を加えて確認したい場合は修正をctrl+Sで保存して、ブラウザをリロード
